Evoluzione: Proprietà Logiche CSS 📐

Siamo abituati a pensare in termini di "sopra, sotto, destra, sinistra". Ma cosa succede quando il testo non scorre da sinistra a destra? Le proprietà logiche si adattano alla direzione del contenuto, garantendo un layout coerente in ogni lingua.

do_not_disturb

Proprietà Fisiche (Limitate)

1. Orizzontale (LTR)

Margine a sinistra

2. Verticale (Giapponese)

物理的な余白

3. Destra-Sinistra (Arabo)

هوامش مادية
margin-left: 2rem; /* Sempre a sinistra */

Il margine resta bloccato a sinistra anche se l'inizio della riga è a destra (Arabo) o se si scrive in verticale.

check_circle

Proprietà Logiche (Universali)

1. Orizzontale (LTR)

Inizio riga

2. Verticale (Giapponese)

論理的な余白

3. Destra-Sinistra (Arabo)

هوامش منطقية
margin-inline-start: 2rem; /* All'inizio della riga */

Il margine "capisce" dov'è l'inizio della riga in base alla lingua e alla direzione del testo.
